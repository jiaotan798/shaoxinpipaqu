# 构建说明

## 准备依赖

克隆完整仓库，各端会复用公共源码和资源。将目标对应的[《朋友的酒》0.1.19](https://github.com/jiaotan798/friendswine/releases/tag/v0.1.19) JAR 按 Release 原文件名放在仓库根目录的 `local-deps/`。首次构建需要联网下载 Gradle 和公开依赖。

构建 1.21.1 NeoForge 版需要 JDK 21，还需把 `ysm-2.6.5-neoforge+mc1.21.1-release.jar` 和 `touhoulittlemaid-1.5.3-neoforge+mc1.21.1.jar` 放在 `local-deps/`。两者是该端口的编译依赖，玩家可按需安装。主端命令和产物位置见 [README](../README.md#构建源码)。

## 其他版本和加载器

在仓库根目录用目标自带的 Gradle Wrapper 构建。成品在该目标目录的 `build/libs/`，安装时选带对应 Minecraft 版本和加载器的 JAR。

| 目标 | 构建 JDK | PowerShell 命令 |
| --- | --- | --- |
| 1.20.1 Forge | 17 | `./ports/forge-1.20.1/gradlew.bat -p ports/forge-1.20.1 build` |
| 1.20.1 Fabric | 21 | `./ports/fabric-1.20.1/gradlew.bat -p ports/fabric-1.20.1 build` |
| 1.21.1 Fabric | 21 | `./ports/fabric-1.21.1/gradlew.bat -p ports/fabric-1.21.1 build` |
| 26.1.2 NeoForge | 25 | `./ports/neoforge-26.1.2/gradlew.bat -p ports/neoforge-26.1.2 build` |
| 26.1.2 Fabric | 25 | `./ports/fabric-26.1.2/gradlew.bat -p ports/fabric-26.1.2 build` |

运行 Fabric 1.20.1 的开发游戏时，还需要让 Gradle 找到 JDK 17。

## 成品检查和资源重导出

六端构建完毕后，用 Python 3.11 或更高版本运行 `python ./scripts/verify-build.py --matrix`。如需重新导出素材，把 FFmpeg 加入 `PATH`，或将 `FFMPEG` 指向其可执行文件，再运行 `python ./scripts/prepare-resources.py`。

各端口源码包含验收探针。运行 26.1.2 NeoForge 的服务端 GameTest 前，将与《朋友的酒》0.1.19 匹配的源码放入 `local-deps/friendswine-source/`，先在前置的 26.1.2 NeoForge 工程运行 `compileJava`。随后在本仓库根目录运行 `./ports/neoforge-26.1.2/gradlew.bat -p ports/neoforge-26.1.2 runGameTestServer -PgameTests`。已执行的构建和测试见[验证记录](../VALIDATION.md)。
