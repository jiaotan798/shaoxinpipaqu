# 模组设置

## 卡点显示

两项设置只影响当前客户端，默认开启。修改后立即生效，重启游戏会保留选择。

| 设置 | 配置键 | 默认值 | 作用 |
| --- | --- | --- | --- |
| 显示卡点文字（MJ） | `showCueText` | `true` | 显示六个 MJ 文字及回弹、轻抖和柔光 |
| 显示卡点表情包 | `showMemePictures` | `true` | 显示大狗、白菜和肥嘟嘟表情包 |

- **NeoForge、Forge**。从「模组 → 烧心琵琶曲 → 配置」进入。
- **Fabric 1.20.1**。装有可选的 Mod Menu 时，从模组列表打开配置。
- **Fabric 1.21.1、26.1.2**。在游戏中输入下列客户端命令。将 `true` 换成 `false` 可以关闭对应效果。

```text
/shaoxinpipaqu settings showCueText true
/shaoxinpipaqu settings showMemePictures true
```

也可以退出游戏后直接编辑当前实例的配置。NeoForge 使用 `config/shaoxinpipaqu-client.toml`，Forge 和 Fabric 使用 `config/shaoxinpipaqu-client.properties`。重新开启显示时，画面会跟随歌曲当前进度。

三档飞行的环绕速度沿用《朋友的酒》的服务端圈速设置。上面的两个显示开关只控制本机画面。
