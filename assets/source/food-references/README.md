# 食物物品图标

我把两张透明图做成了 128×128 的物品贴图。忘情牛肉面用的是一张牛肉面照片，野生狗奶用的是网络素材里的蓝白包装。

- **忘情牛肉面**的原作是 avlxyz 的《牛肉麵 Chinese Braised Beef Noodles - whole bowl visible》。我用 AI 去掉背景、补全碗沿，再缩成游戏贴图。原图和衍生图均采用 CC BY-SA 2.0。 [原作](https://www.flickr.com/photos/10559879@N00/371505766/) · [文件与署名记录](https://commons.wikimedia.org/wiki/File:牛肉麵_Chinese_Braised_Beef_Noodles_-_whole_bowl_visible.jpg) · [许可](https://creativecommons.org/licenses/by-sa/2.0/) · [透明图](beef-noodles-cutout-ai.png) · [处理说明](beef-noodles-cutout-ai.md)
- **野生狗奶**保留了蓝白纸盒和正面的狗。 [透明图](wild-dog-milk-cutout-ai.png) · [处理说明](wild-dog-milk-cutout-ai.md)
